# Football 101: Read the Game

An interactive, single-page guide that helps newcomers follow a football match.

## Who it is for
International students and anyone who wants to watch football with friends but does not know the rules or positions yet.

## What it does
- **Formation explorer:** choose 4-4-2, 4-3-3, 3-5-2 or 4-2-3-1 and select any player to see what the role does.
- **Offside lab:** move the attacker and the passer to see when offside is called, and see why it never applies directly from a throw-in, goal kick or corner kick.
- **Rules in plain words:** seven short explanations of the most common rules.
- **Quiz:** five questions with instant feedback.

## How to run
Open `index.html` in any modern browser. No install, no build step, no server.

## How to publish (optional)
In the GitHub repo go to Settings > Pages, choose the `main` branch and the root folder, and save. The site appears at the address GitHub shows.

## How it was made
Built with AI assistance (Claude) in a single HTML file with plain JavaScript and SVG. Content was checked against the IFAB Laws of the Game (see report).

## Limits
Simplified for beginners. It does not cover every detail of the Laws (for example handball, advantage, or tournament-specific rules).
